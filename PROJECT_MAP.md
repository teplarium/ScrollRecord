## 1. Overview (30 seconds)

ScrollRecord is a desktop app (Windows + Linux first, macOS later) that renders smooth scroll videos of websites for any device. It draws a visual cursor over the video and can also record single-block animations. It has two layers:

- **Rust core** (`crates/`): all logic, as small independent libraries.
- **Desktop app** (`apps/desktop/`): a Tauri shell (`src-tauri/`, thin Rust glue) plus a React UI (`src/`).

The UI talks to Rust only through **IPC commands**. Their data types are defined in Rust and **generated** into TypeScript.

```
React UI (apps/desktop/src)
   │  shared/ipc/commands.ts  ── typed wrappers, Result-based
   ▼
Tauri shell (apps/desktop/src-tauri)  ── thin command handlers
   ▼
sr-ipc (contract DTOs) ──► sr-core (domain types, error codes)
sr-diagnostics (logging)
   ▲
sr-cli (`scrollrecord` command)  ── same libraries, no UI
```

Planned pipeline (Phases 1–4): `sr-site → sr-browser → sr-analyzer / sr-timeline → sr-capture → sr-cursor → sr-compositor → sr-encoder`, orchestrated by `sr-render`. See HANDOFF §7.2.

## 5. If X breaks, look at Y

| Symptom | Where to look |
|---|---|
| Footer shows `SR-0003` | UI opened outside the desktop app. Use `pnpm dev`, not `pnpm dev:ui` |
| Footer shows `SR-0001` | `shared/ipc/errors.ts` (what was thrown); the command handler in `src-tauri/src/commands/` |
| New Rust type missing in TypeScript | Add `#[derive(TS)] #[ts(export)]`, then run `cargo test`; output goes to `shared/ipc/generated/` |
| CI: "generated bindings are out of date" | Run `cargo test --workspace` locally and commit `shared/ipc/generated/` |
| CI: `every_code_is_documented_in_errors_md` fails | Add a `## SR-xxxx` section to `docs/ERRORS.md` |
| CI: "has English text for every Rust error code" fails | Add `errors.SR-xxxx` to `i18n/locales/en/common.json` |
| ESLint: `react/jsx-no-literals` | Visible text was typed directly in JSX; move it to the locale file and use `t("...")` |
| No log files | `sr-diagnostics`; error `SR-0101`; check the folder in §6 |
| Window doesn't open on Linux | WebKitGTK missing: install `libwebkit2gtk-4.1-0` |
| *(Phase 1+)* video stutters | `sr-capture` (deterministic mode), time shim |
| *(Phase 1+)* block not found on mobile | `sr-analyzer` locators, `overrides` in the flow |
| *(Phase 1+)* video won't encode | `sr-encoder`, ffmpeg log in diagnostics |

## 7. Dependency rules

1. `sr-core` depends on no other ScrollRecord crate.
2. Library crates never depend on `sr-cli` or `sr-desktop`.
3. Order (lower may not import higher): `core` → `ipc` / `diagnostics` → *(Phase 1+)* `site` / `browser` → `analyzer` / `timeline` → `capture` / `cursor` / `compositor` / `encoder` → `render` → `cli` / `desktop`.
4. UI features import from `shared/` and `i18n/`, never from another feature.
5. The UI reaches Rust **only** through `shared/ipc/commands.ts`.
